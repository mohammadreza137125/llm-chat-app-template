# Z.SHOP Skin Consultant

این بسته، قالب فعلی Cloudflare Worker را به چت‌بات فارسی مشاوره پوست و معرفی محصول تبدیل می‌کند.

## انتشار

محتویات این پوشه را در ریشه مخزن `mohammadreza137125/llm-chat-app-template` جایگزین کنید. فایل‌های موجود دیگر مانند `package-lock.json` می‌توانند باقی بمانند. با ثبت تغییرات در شاخه `main`، Cloudflare به‌صورت خودکار Deploy می‌کند.

## آدرس‌ها

- پیش‌نمایش کامل: `/`
- API چت: `/api/chat`
- اسکریپت شناور: `/widget.js`

## داده محصولات

محصولات منتشرشده و موجود از WooCommerce Store API دامنه `https://zeinab-facial.skin` خوانده می‌شوند و برای این بخش API Key لازم نیست.
